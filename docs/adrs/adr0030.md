# ADR-0030 — Complete explicitly linked tickets after human PR merge

## Status

Accepted

## Date

2026-08-26

## Decision

A least-privilege GitHub Action runs only after a human merges a pull request
into `main`. It accepts exactly one full-line `Battalion-ticket: #<number>`
marker in the PR body, validates the linked Issue through the ADR-0027 schema,
and acts only when that Issue is open and `status:in-review`.

The action removes the active label before closing the Issue, regenerates the
two status projections, and commits only `README.md` and `docs/status.md`.
Already closed, schema-valid tickets are reconciliation states: retries only
regenerate the projections. Invalid markers or lifecycle states fail without
mutation. The action cannot approve or merge PRs and does not infer a ticket
from a branch, title, commit, or ordinary issue reference.

## Consequences

The canonical Issue transition and generated projections stay aligned after
merge, while pre-merge review retains `sync_status.py --check` as its guard.
Branch protection that prevents the generated commit fails visibly and leaves
the Issue as the authoritative completed record until recovery.
