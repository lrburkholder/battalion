# ADR-0030 — Complete explicitly linked tickets after human PR merge

## Status

Accepted

## Date

2026-08-26

## Decision

A least-privilege GitHub Action runs only after a human merges a pull request
into `main`. It accepts exactly one full-line `Battalion-ticket: #<number>`
marker in the PR body, validates the linked Issue through the ADR-0027 schema,
and acts only when that Issue is open and `status:in-review`.

The action removes the active label before closing the Issue. Already closed,
schema-valid tickets are reconciliation states. Invalid markers or lifecycle
states fail without mutation. The action cannot approve or merge PRs and does
not infer a ticket from a branch, title, commit, or ordinary issue reference.

## Consequences

The canonical Issue transition is explicit after merge. Pre-merge review
validates the canonical Issue corpus, while Pages publishes status through its
separate rendering boundary.

## Amendment (BTN-128, 2026-08-27)

The lifecycle Action no longer regenerates or commits status Markdown. It keeps
the least-privilege lifecycle mutation boundary; public status is rendered by
the Pages publication pipeline under ADR-0031.
