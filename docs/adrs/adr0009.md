# ADR-0009 — Count Rejection Causes Per Checkpoint Type

## Status

Accepted

## Date

2026-08-01

## Implementation status

Implemented in v1 by BTN-12.

## Context

Interrupt trigger 1 pauses after the same Reviewer root cause is rejected
twice. Similar wording at RED, GREEN, and REFACTOR checkpoints does not
necessarily represent the same repeated failure.

## Decision

Count repeated rejection causes independently for RED, GREEN, and REFACTOR
checkpoints. Record the checkpoint on each rejection and calculate its cycle
number within that checkpoint type.

## Rationale

Checkpoint-local counters detect genuine repeated failure without combining
unrelated failures from different stages.

## Consequences

- Rejection records include checkpoint identity.
- Interrupt evaluation compares causes only within the same checkpoint type.
- The added state field requires versioned state-contract discipline.
