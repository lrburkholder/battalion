# ADR-0012 — Confidence Represents Operational Usefulness

## Status

Proposed

## Date

2026-08-05

## Implementation status

Future-facing; not part of the shipped v1 graph.

## Numbering note

This decision was originally recorded as ADR-0009. It was renumbered because
ADR-0009 was already assigned to checkpoint-local rejection counters in the v1
architecture plan.

## Context

Instinct retrieval needs ranking. A confidence value could represent subjective
trust, activation status, or observed usefulness, and those meanings should not
be conflated.

## Decision

Confidence represents observed operational usefulness. Derive it from operator
feedback; do not edit it directly or use it to determine whether an instinct is
active. Status and confidence remain separate concepts.

## Rationale

Operational evidence grounds ranking in real use. Separating confidence from
status allows an active instinct to have limited evidence and prevents a
superseded instinct from remaining active merely because it once ranked highly.

## Consequences

- Retrieval requires usage and feedback statistics.
- Human feedback improves ranking over time.
- Instinct lifecycle state must be modeled separately from confidence.
