# ADR-0007 — Accepted Instincts Are Immutable

## Status

Accepted

---

## Context

Engineering guidance evolves.

Editing existing knowledge destroys historical context and makes it impossible
to understand how Battalion's engineering practices developed over time.

---

## Decision

Accepted Instincts are immutable.

If guidance changes:

- create a new instinct
- reference the previous instinct
- optionally mark the previous instinct as superseded

Existing instincts are never rewritten.

---

## Consequences

Positive

- Complete engineering history
- Traceable evolution
- Stable references
- Easier debugging

Negative

- Repository grows over time
- Requires supersession metadata

---

## Rationale

Repository history is an asset.

Battalion exists to accumulate engineering judgment.

Historical context is valuable even when guidance changes.
