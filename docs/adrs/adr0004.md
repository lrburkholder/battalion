# ADR-0004 — Implement Native Battalion Roles

## Status

Accepted

## Date

2026-08-01

## Implementation status

Implemented in v1.

## Context

Earlier Regiment and Copilot material could inform Battalion, but wrapping
those agents would preserve interfaces and authority assumptions that do not
match Battalion's LangGraph and state contracts.

## Decision

Implement Architect, Driver, Reviewer, and Refactorer as native Battalion graph
nodes rather than wrappers over earlier agents.

## Rationale

Native roles can be designed around Battalion's explicit state, write-scope,
interrupt, and provider boundaries from the start.

## Consequences

- Historical material is guidance, not a runtime dependency.
- Role behavior and prompts must conform to Battalion's own contracts.
- Changes to role authority remain Battalion architecture changes.
