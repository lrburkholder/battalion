# ADR-0003 — Keep Typer as a Thin CLI

## Status

Accepted

## Date

2026-08-01

## Implementation status

Implemented in v1.

## Context

Battalion needs `run`, `resume`, `status`, and setup commands without moving
runtime policy into a user-interface adapter.

## Decision

Use Typer for the command-line interface and keep command handlers as thin
adapters over reusable runtime functions.

## Rationale

Typer fits the type-hint-driven codebase and provides concise subcommands while
leaving graph behavior independently testable.

## Consequences

- CLI handlers own argument parsing and presentation, not graph policy.
- Runtime functions must remain usable without invoking the CLI.
- CLI tests can focus on adaptation while graph tests cover orchestration.
