# ADR-0010 — Accepted Instincts Are Immutable

## Status

Accepted

## Date

2026-08-05

## Implementation status

Implemented by BTN-21 as a local, append-only Intel repository; not part of the
shipped v1 graph.

## Numbering note

This decision was originally recorded as ADR-0007. It was renumbered because
ADR-0007 was already assigned to expected-outcome review in the v1 architecture
plan.

## Context

Engineering guidance evolves. Editing accepted knowledge in place destroys the
historical context needed to understand how Battalion's engineering practices
developed.

## Decision

Accepted instincts are immutable. When guidance changes, create a new instinct,
reference the previous one, and optionally mark the previous instinct as
superseded. Never rewrite the existing instinct.

## Rationale

Repository history is an asset. Stable records make the evolution of
engineering judgment traceable and debuggable.

## Consequences

- References to accepted instincts remain stable.
- Supersession metadata is required when guidance changes.
- The knowledge repository grows over time.
