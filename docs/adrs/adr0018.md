# ADR-0018 — Use Literal, Inspectable Instinct Retrieval

## Status

Accepted

## Date

2026-08-13

## Implementation status

Implemented by BTN-24.

## Context

BTN-21 stores immutable accepted Instincts and exposes active records, while
BTN-26 provides Battalion's bounded role-context path. BTN-24 must connect
those contracts without introducing confidence claims, semantic similarity,
or a second prompt-assembly mechanism. The free-form applicability and tag
fields need rules whose results an operator can reproduce and inspect.

## Decision

Retrieve only records returned by `IntelRepository.list_active()`. A record is
eligible when its audience contains the execution role, no normalized literal
`exclude` phrase occurs in the ticket and specification text, and either its
`include` list is empty or at least one normalized literal `include` phrase
occurs there. Exclusions take precedence.

Order eligible records by descending count of matched applicability phrases,
then descending count of matched tags, then ascending stable Instinct ID. Tags
refine ordering but do not broaden applicability. Normalization case-folds text
and treats punctuation as word separators; it performs no stemming, synonym
expansion, embeddings, or model calls.

Render selected Instincts through `battalion.context`, before the larger task
and workspace sections. Each admitted entry includes its stable identifier,
recommendation, applicability description, and tags. A dedicated allowance
admits only whole entries, preserving BTN-26's overall context bound. Architect,
Driver, Reviewer, and Refactorer query independently for their own audience.

The local repository path is `<project>/.battalion/intel`, keeping knowledge
project-local. Retrieval exposes an inclusion or exclusion decision for every
active record considered so tests and future operator surfaces can explain the
selection.

## Consequences

- Identical repository and task inputs produce identical selections and order.
- Superseded records and candidates cannot enter retrieval through this path.
- Different roles can receive different knowledge for the same ticket.
- Literal wording may miss conceptually related guidance; this is an explicit
  transparency tradeoff for the first vertical slice.
- Semantic retrieval, feedback, confidence scoring, and cross-project sharing
  require later decisions and remain out of scope.
