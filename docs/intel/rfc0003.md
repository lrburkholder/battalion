# RFC-0003 — Intel

## Summary

Intel supplies engineering knowledge to Battalion nodes.

Intel does not generate knowledge.

Intel does not modify knowledge.

Intel determines which accepted instincts are most relevant to the upcoming task.

---

## Responsibilities

Intel performs four stages.

### Eligibility

Remove instincts that cannot be considered.

Examples:

- candidate
- retired
- inactive
- wrong project
- wrong audience

---

### Retrieval

Find potentially relevant instincts.

Initial implementation:

- trigger matching
- node audience
- tags

Semantic retrieval is deferred.

---

### Ranking

Order retrieved instincts.

Inputs include:

- relevance
- confidence

Ranking algorithms are intentionally replaceable.

---

### Prompt Assembly

Produce a consistent context block supplied to the execution node.

Intel presents original instincts.

Intel does not summarize instincts.

---

## Design Goals

- deterministic
- explainable
- replaceable
- auditable

---

## Future Work

- semantic search
- embeddings
- project federation
- personalized ranking
