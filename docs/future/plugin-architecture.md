# Plugin Architecture Planning Brief

**Status:** Superseded by RFC-0009
**Ticket:** BTN-46
**Target:** Post-v2 architecture
**Decision:** [`docs/rfcs/rfc0009.md`](../rfcs/rfc0009.md)

This planning brief has been superseded by RFC-0009, which records the accepted BTN-46 architecture for Battalion plugins, isolated third-party execution, permissioned organization approval, and the Quartermaster administrative surface.

RFC-0006 and ADR-0025 remain authoritative for Battalion-owned integration capability semantics. RFC-0009 defines how independently packaged provider adapters and transports may participate beneath those contracts without becoming a second policy authority.
